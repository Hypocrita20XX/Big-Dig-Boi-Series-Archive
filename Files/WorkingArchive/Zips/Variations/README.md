# Zip Files With Variations For The Entire Series

This is an archive for every zip for each pak in the Big Dig Boi series with variations that aren't on Mod io. That site isn't designed for something like this, so it will live here and on the various places I decide to share it.

For now, there are two variants, one which changes the PickAxeDigSize to a value of 225 (the original value I used before changing to 180) and another which changes it to 325.
